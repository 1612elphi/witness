# Witness

Witness is a front-end forge-style implementation of the Lore Version Control system made by Epic Megagames.

## Stack

This implementation is build with Fresh + Preact, which the design system requires. The design system used is Sunbeam Studio's Beam Design Language.

## Features for this MVP

The following features of the Lore VCS are implemented:
	
	Repository creation
	File browsing
	Visual branching
